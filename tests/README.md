# Cross-cutting tests

Integration and end-to-end tests that span more than one app (e.g. "create a customer on
the website, verify it syncs to mobile") live here. Most tests live beside the code they
test inside `apps/mobile/src/**` — see [`docs/getting-started.md`](../docs/getting-started.md).
Populated starting in Stage 3 (offline synchronization) and Stage 7 (website integration).
