# Play Store screenshots

Drop finished screenshots in `phone/` (one subfolder per device class if we
ever add tablet/7-inch/10-inch shots later).

## Play Console requirements (phone)

- JPEG or 24-bit PNG, **no alpha channel**
- 2–8 screenshots
- Each side between 320px and 3840px
- Aspect ratio between 16:9 and 9:16 (portrait screenshots from a real
  device build, e.g. 1080x2340, are fine)

## Naming

Number them in the order they should appear in the listing:

```
phone/01-dashboard.png
phone/02-orders.png
phone/03-billing.png
...
```
